# 排机明细行内展开设计

## 目标

点击排机单的“查看明细”后，明细立即显示在该排机单所在行的正下方，不再固定显示在整张排机列表底部。

## 交互

- 同一时间只展开一张排机单。
- 点击另一张排机单的“查看明细”时，上一张自动收起，新明细在新排机单行下展开。
- 明细加载失败时保持原有错误提示，不展开错误数据。
- 分页、导出、删除、明细编辑、复制、排序、拖拽和完成状态筛选保持现状。

## 实现

- 使用 Ant Design Table 的受控 `expandable` 配置。
- `expandedRowKeys` 由 `selectedSchedule.id` 生成，保证只有当前选中排机单展开。
- 将原来的底部明细卡片提取为 `renderScheduleDetail()`，通过 `expandedRowRender` 渲染到所选排机单行下方。
- 隐藏表格默认展开图标，继续只用“查看明细”按钮触发加载和展开。
- 删除原来列表卡片之后的独立明细渲染，避免重复显示。

## 验收标准

- 点击任意“查看明细”后，紧邻该排机单行的下一行是排机明细。
- 页面中只存在一个展开明细区域。
- 点击另一排机单时，明细移动到新排机单下方。
- 编辑、复制、按机台号排序等明细操作仍可使用。
- 前端构建和现有回归测试通过。
