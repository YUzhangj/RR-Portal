# 华登机台扩充至 38 台设计

日期：2026-07-28

## 目标

将华登（C 车间）的正常编号机台由 34 台扩充至 38 台，新增：

- `C-35#`
- `C-36#`
- `C-37#`
- `C-38#`

`其他机台`与`吹气机台`属于特殊机台，不计入 38 台正常编号机台。

## 数据定义

四台新增机台沿用现有华登机台默认属性：

- 品牌：博创
- 吨位：150T
- 机械手：三轴单臂
- 状态：启用
- 车间：C

## 变更范围

1. 将数据库初始化逻辑中的华登预置数量由 34 改为 38。
2. 在机台种子数据中加入四台新增机台。
3. 在当前运行数据库中幂等新增四台机台，不覆盖已有机台数据。
4. 不调整 A、B 车间，不修改特殊机台，不改变现有排产记录。

## 验收标准

- 华登正常编号连续覆盖 `C-1#` 至 `C-38#`。
- 正常编号机台恰好 38 台且没有重复编号。
- 加上两台特殊机台后，华登机台接口共返回 40 条记录。
- `C-35#` 至 `C-38#` 的属性符合本设计的数据定义。
- 重复执行初始化不会重复插入机台。
- 服务健康接口与前端构建验证通过。
