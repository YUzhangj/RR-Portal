# VoyagePlex 邮件解析服务

该服务是新系统的一部分，与 `legacy-reference/READ_ONLY_RR_PORTAL` 完全隔离。

规则来源：RR-Portal 船务管理系统 `main@690cbab`。旧代码仅用于行为参考；本服务使用自己的输入输出协议、临时目录和测试。

接口：`POST /v1/email-batches/parse`，表单字段 `files` 可重复上传多个 `.eml`。每封邮件独立解析，单封失败不会中断批次。

## 企业邮箱自动收取

解析服务支持从一个固定船务邮箱通过加密 IMAP 读取邮件。由管理员在运行解析服务的云服务器上配置以下环境变量，授权码不要写入仓库：

| 变量 | 说明 |
| --- | --- |
| `VOYAGEPLEX_MAIL_ADDRESS` | 完整企业邮箱地址 |
| `VOYAGEPLEX_MAIL_AUTH_CODE` | 该邮箱的客户端授权码 |
| `VOYAGEPLEX_MAIL_IMAP_HOST` | 可选，默认 `imaphz.qiye.163.com` |
| `VOYAGEPLEX_MAIL_FOLDER` | 可选，默认 `INBOX` |

云服务器须能向 `imaphz.qiye.163.com:993` 建立加密出站连接。解析服务不配置上述邮箱地址与授权码时，自动收取保持关闭。后台每 5 分钟读取一次，也可在“信息导入 → 邮件解析”点击“立即同步”。首次同步读取最近 7 天邮件，每次最多处理 50 封；后续通过邮箱 UID 继续读取。每日邮件按固定船务邮箱的 IMAP 收件时间归类，以北京时间（UTC+8）划分日期；转发邮件的原始发信日期不参与归类。邮件只进入待确认批次，人工确认后才创建或更新走柜任务。系统使用只读文件夹连接和 `BODY.PEEK[]`，不会把邮件标记为已读。

真实邮件样本只保留在用户授权的本地目录，不复制进仓库。可用以下命令执行回归验证：

```bash
python tools/check_customer_samples.py "/path/to/customer-emails"
```

运行：

```bash
python -m pip install -r requirements.txt
uvicorn app.main:app --reload --port 8091
```


## 华登板块配置

产品信息库共用；邮箱、任务、联系人、同步断点和库存目录按公司隔离。
兴信继续使用现有环境变量。华登单独设置：

- `VOYAGEPLEX_HUADENG_MAIL_ADDRESS`：收件邮箱。
- `VOYAGEPLEX_HUADENG_MAIL_AUTH_CODE`：邮箱客户端授权码，仅放在服务环境配置中。
- `VOYAGEPLEX_HUADENG_MAIL_IMAP_HOST`：IMAP 主机，默认 `imaphz.qiye.163.com`。
- `VOYAGEPLEX_HUADENG_MAIL_FOLDER`：邮箱文件夹，默认 `INBOX`。
- `VOYAGEPLEX_HUADENG_INVENTORY_DIR`：服务端华登库存目录；未设置时不会读取兴信目录。

浏览器本地库存文件夹需切换到华登后，在系统设置中单独授权。
现有用户默认兴信权限，管理员可分配华登或两家公司权限。
首次启动自动备份旧 SQLite 数据库并补齐公司字段，已有业务记录归入兴信。
华登导出支持整柜及交仓；混装组共用件数、毛重及体积只填第一行，各行净重单独填写。
整个集装箱重量 = 表中毛重合计（已含填写的卡板重量）+ 填充物重量 + 柜重；未填写柜重则留空。

### 华登个人邮箱

兴信现行解析规则及华登核对事项见[兴信邮件解析规则核对](兴信邮件解析规则核对.md)。

163个人邮箱服务器填写 `imap.163.com`，文件夹填写 `INBOX`，使用开启IMAP后生成的授权码。连接测试及同步在服务器支持ID扩展时声明客户端身份，以兼容网易的第三方客户端安全检查。安全限制与文件夹访问失败分别提示；本地测试通过后仍需部署并在线验证。

华登邮箱在系统的「用户管理 → 编辑 → 华登个人邮箱」中绑定，每个账号绑定一个邮箱；填写邮箱地址、IMAP服务器、文件夹和邮箱授权码。授权码由API使用ASP.NET Core Data Protection加密保存，接口不会返回授权码。部署或迁移服务器时必须保留API运行用户的Data Protection密钥目录（数据库所在目录的 `data-protection-keys` 子目录，云端为 `/app/data/data-protection-keys`），否则需要重新填写授权码。

华登同步按有效用户分别运行，不再使用公司的统一环境变量邮箱。API向内部解析服务通过POST请求体传递解密后的连接资料，不放入URL；解析服务应只允许API在内网访问。每位船务员只能查看、修改和确认自己的邮件；管理员可筛选人员或查看全部。UID断点、读取起始日期和同步设置分别记录。同一邮箱不能同时绑定两个账号。

确认生成的华登任务对华登船务员共享，记录负责船务员与来源邮箱，不在任务接口返回私人邮件主题或来源邮件列表。原有华登邮件默认保留为未分配（owner=0），仅管理员可见，迁移不擅自归入某个船务员。兴信邮件规则保持原样。

### 邮箱状态与共享任务权限

同步设置按人员显示「未配置、已配置待连接、连接成功、连接或同步异常」。连接测试结果和时间保存在用户记录；更换连接资料或授权码会使旧测试结果失效。测试草稿后保存时，API验证与该草稿匹配的加密测试凭据；不会因为前端传入“成功”就标记已连接。同步失败优先显示异常。

华登船务员可查看、修改和删除本公司共享任务，可相互代操作；仓务原有移交后操作规则继续适用。手工新建任务记录创建人作为负责人，负责人用于记录来源，不限制船务员操作。

跨邮箱的同一通知使用发件人、主题、发送日期、正文与附件内容校验，忽略收件人、投递头及MIME边界。确认时只关联已存在的任务，不覆盖其他负责人的任务；变更邮件可由当前邮箱船务员确认并更新共享任务。旧邮件继续使用已有文件指纹和SO关联规则，不自动推断缺失的内容校验。

### 厂区角色权限

管理员可访问两厂区全部功能。主管只可访问所绑定厂区全部功能，管理本厂区船务员、仓库文员和华登人员邮箱，不能管理管理员或主管、不能授予跨厂区权限。船务员只处理本厂区邮件与共享任务，华登邮件仍限本人邮箱。仓库文员只访问本厂区任务和库存。非管理员账号须绑定一个厂区；旧的双厂区非管理员账号须由管理员重新指定厂区。产品信息库继续共用。
