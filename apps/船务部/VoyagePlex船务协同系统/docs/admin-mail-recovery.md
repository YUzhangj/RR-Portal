# 管理员历史失败邮件补信

入口：管理员登录后，打开「邮件工作台 → 历史失败补信」。华登须先选择对应人员邮箱；兴信使用现有共享邮箱。普通船务员和主管不显示此入口，后端同样只允许有效管理员访问。

## 操作

1. 核对厂区、邮箱地址、邮件主题和收件时间。列表每页 20 条，只显示系统已记录的失败邮件。
2. 勾选最多 5 封，再点击「重试所选」并确认。初核已识别的人工处理、直接任务关联或邮箱身份问题会禁止选择；初步可选的记录仍须通过提交时的完整校验，包括间接任务关联与原邮件内容校验，校验未通过时保留原记录。
3. 查看逐封结果。「已读取，待工作台核对」表示重新读取成功；「仍读取失败，原记录保留」表示尚未恢复。成功后到邮件工作台核对，业务任务仍须另外确认。
4. 网络中断或结果不明时，先刷新列表核对，不连续重复提交。页面不会自动重试；切换邮箱、翻页或刷新会清除选择。

本入口调用既有的安全重试服务，保留同步断点及原邮件 ID，不跳过邮件、不重置游标、不自动建立任务。它不推测 UID 间隙，也不处理从未存入系统的邮件；此类缺信仍须先核对邮箱范围和服务端证据。

## 发布与权限

前端和 API 须一起发布。新增只读接口 `GET /api/imports/email/mailbox/failed?page=N`；前端代理仅接受固定接口与有限参数，重试仍使用 `POST /api/imports/email/mailbox/retry-failed`。没有数据库迁移、授权码或环境变量变更。部署本身不会启动历史补信。

启动维护分页修复另见 PR #1083。此入口不替代该修复，也不要求重置同步状态。服务器原有容量配置应在启动分页修复完成上线与资源验证后单独评估。
