# PrintLink 3D 打印协同平台

独立应用，提供清溪、湖南、河源、印尼的订单、附件、反馈、账号权限及生产协同；清溪 Windows 通过桥接读取原 3d-server 的打印机状态。

本 PR 不修改 RR Portal 的现有 Compose、Nginx、门户菜单或登录。使用本目录的独立 Compose 项目部署；与门户 SSO 和子路径集成尚未实现。前端使用根路径，请分配专用 HTTPS 站点，不要直接挂到门户子路径。

## 运行与测试

需要 Node.js 24 或更高版本，无需安装 npm 依赖。`npm start` 启动本地模拟平台（3100）、内部生产服务（3102）和模拟采集控制台（3103）。`npm test` 使用临时数据库及纯测试资料，覆盖订单权限、附件、质检入账、状态重放、备份恢复和桥接；不依赖历史业务数据。

本地演示自动创建示例订单，生产模式使用独立数据目录和管理员登录。只允许一个业务实例操作同一数据目录。备份前停机，正常退出后释放数据目录锁。
