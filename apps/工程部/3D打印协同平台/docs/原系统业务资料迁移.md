# 原系统业务资料迁移

设备状态桥接不迁移产品、材料、库存和历史生产记录。云端首次部署为空库；需要从清溪 Windows 原系统导出最新业务 JSON，并在云端导入。无需更新桥接程序。

## 操作步骤

1. 管理员部署此 PR 后，在 Windows 打开原 3d-server（http://127.0.0.1:3000 或局域网地址），进入“设置”→“导出数据(JSON)”，保存文件。迁移期间暂停两端业务编辑，避免库存及记录继续变化。
2. 登录云端新平台管理员账号，进入“生产资料”→“设置”→“导入原系统资料（先预览）”，选择刚导出的文件。
3. 核对预览的产品、材料、库存条目、排期、记录天数/条数、维修、杂费、入库记录数量，确认后导入。
4. 导入会保存迁移前快照到 production.sqlite 的 import_backups 表，并返回快照编号。原文件和 Windows 旧系统不被修改。快照不代替包含附件的停机备份。
5. 刷新后将仪表盘、每日记录和报表日期选到原系统实际有记录的日期/月份，核对金额及数量。仅看当天可能仍为 0。

## 合并规则与冲突

仅追加不存在的记录；同 ID 且内容一致的资料跳过。库存同名但数值不同、同编号资料内容不同、休息日状态不同或已有业务情况下的成本设置冲突，会阻止整次导入，云端保持不变。预览后云端数据发生变化也会要求重新预览。

不要为绕过冲突清空云端数据、修改文件中的 ID 或篡改库存。把冲突信息交给管理员核对原系统和云端资料，决定最终业务数据后再执行专门迁移。保留云端关联订单的记录与排期，源文件禁止包含 cloudJobId。

此功能是一次性业务迁移，不是持续双向同步。完成核对后确定业务切换时点：旧系统继续采集，新平台作为唯一正式记账入口，避免两端重复扣库存。

JSON 内嵌图片会随产品字段保留；原系统单独保存在 product-files 目录的附件不在业务 JSON 中，需要管理员另行复制并核对产品 ID。此功能不迁移账号、登录密码、设备凭据、原系统外部附件或打印机控制设置。专用导入及业务全量保存默认支持 64MiB 请求（包括 JSON 包装）；管理员可用 PRODUCTION_JSON_LIMIT_MB 调整为 1–256MiB。反向代理的 client_max_body_size 和超时需配套调整。大文件解析、合并和快照会占用额外内存，应在低峰执行，不要并发导入。

## 管理员快照恢复

如需恢复迁移前快照，先停止全部云端业务进程，并备份整个数据目录；在 production.sqlite 的 import_backups 中按返回编号获取 value，核对后恢复 snapshot(id=1)。不要在线回滚：回滚会撤回迁移后生产资料修改，且需检查与订单库的一致性。

验证：合成资料覆盖预览、同 ID 冲突、库存冲突、重复导入、云端任务保留、管理员权限、预览过期和迁移前快照。现场最新数据尚未导入，需按上述步骤完成并核验。

## 日常分工与图片加载

已确定日常业务统一在新平台维护：生产记录、产品、材料库存、排期、维修和杂费都在云端录入。Windows 保留原系统和桥接程序运行，上传打印机在线状态、进度、温度、任务名称等设备信息；原系统自行新增的业务记录不自动复制到云端。关联订单的生产记录继续由新平台质检流程生成，防止重复记账。

生产资料首屏使用精简接口，内嵌 PNG/JPEG/WebP/GIF 图片替换为需授权访问的图片地址，查看列表时按需加载。原始快照仍保留完整图片；保存时恢复图片内容，导出 JSON 从服务器读取完整快照，备份可独立迁移。SQLite 的 data_images 表为不可变派生图片缓存，包含在数据库备份内；长期替换大量图片会增加数据库空间，当前不自动清理缓存。

本次加载优化只更新云端服务，无需更新 Windows 桥接，无需重新导入 JSON。

## 订单关联生产排期

在订单工作台打开订单详情，点击“关联生产排期”，系统会带入所选订单。确认产品、实际材料、采集站、平台机台编号、计划日期和单件重量后创建生产任务，自动生成带订单编号的云端排期。每张订单只能关联一个生产任务；已手动标为“打印中”但没有任务的订单可补关联，并保持打印中状态。此入口创建新的关联排期，不会自动匹配或合并历史手工排期。

现场桥接仍需按原流程将真实打印任务绑定到云端任务，不能仅凭产品同名判断关联。采集到打印开始后订单进入打印中，设备完成后进入任务待质检；质检确认生成生产记录、扣库存，订单进入待交付，确认交付后已完成。关联排期从“关联订单 · 前往处理”进入同一任务处理，不能直接在独立排期编辑框绕过质检。

订单详情显示是否关联及同步状态；排期表显示订单编号，未关联的手工排期标为“独立排期”。生产资料每 15 秒检查版本并读取发生变化的数据。现有历史手工排期保持独立，不能仅凭产品名称自动认领到订单。
