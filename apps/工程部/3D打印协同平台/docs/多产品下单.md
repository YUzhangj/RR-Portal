# 多产品下单

一张申请可以填写 1–50 条产品明细。每条分别保存产品名称、货号、数量、耗材、颜色、打印机器（光固化 / FDM）、需交板日期、备注与工艺要求。

- 点击“＋ 添加产品明细”增加一行。相同产品需要不同耗材或颜色时，分开填写明细。
- 厂区、车间、客户、工程师、跟进人及优先级由整单共用。
- 附件由整单共用，仍为 1–10 个、单个不超过 200MB、合计不超过 500MB；用文件名注明对应产品或货号，文件较多时可上传压缩包。
- 草稿、待接单申请修改、详情均保留所有明细。CSV 每条明细一行，订单编号重复表示同一订单。
- 生产协同选择订单后，选择尚未排产的产品明细，再安排材料和机台。每条有独立任务和数量，独立同步排期。
- 整单所有明细打印完成才进入待交付，交付为整单确认。失败、未排产或已取消待重排的明细不会被算作完成。多产品订单取消一条任务后，该明细可重新安排；其他明细保留。
- 旧单产品订单可继续查看、处理，待接单时也可追加明细。

## 更新与兼容

本次只需更新云端代码，不需要更换 Windows 采集器。首次启动会在事务中迁移订单任务表，保留原任务 ID、采集进度及关联；订单、账号和生产资料不会清空。

部署前保存当前订单 SQLite 数据库一致性备份。迁移后新增的多产品订单不兼容旧版单产品排产代码，不应直接回退旧代码继续写入；需要回滚时先停止写入并恢复升级前一致性备份。

本功能与全业务双向同步共同交付在 PR #909 中。多产品下单本身只涉及云端；双向同步的 Windows 升级和首次对账步骤仍见《双向同步升级》。

验证：本地自动测试覆盖多产品校验、修改保存、重启、逐条排产、数量和材料同步、部分完成、取消重排、整单交付及旧任务迁移；浏览器检查添加/移除、草稿恢复、电脑/手机布局。
