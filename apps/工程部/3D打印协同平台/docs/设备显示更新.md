# 设备显示更新

云端每日记录之前按 1～N 绘制机台，而采集可能映射为 101～121；桥接之前仅传基础状态。此更新按实际上报的编号生成卡片，保留现场编号作为辅助标签，并以白名单传送文件名、温度、剩余时间及层数等显示详情。不会传设备密码、访问码或序列号。

先由管理员更新云端此 PR，再更新清溪 Windows：关闭桥接窗口，将新版包中的 collector 程序文件及新增 shared 文件夹覆盖至 D:/PrintLinkBridge（以实际安装路径为准）。保留 bridge.local.json 和 runtime，不覆盖令牌、机台映射或队列。重新运行原启动脚本，等待约 10 秒后刷新页面。旧系统 3d-server 不需要修改或重启。

当前已授权的机台编号不要随意改回 1～N；订单和排程仍使用平台编号，页面同时展示现场编号。云端历史生产记录与原系统历史记录不是自动双向同步，本更新不导入历史业务资料。现有统计及手工机台配置仍沿用旧业务逻辑，未在本更新重构。

验证：20 项本机自动测试通过，包含机台映射卡片、详情白名单过滤、桥接读取与云端持久化接口；现场 Windows 和云端更新后仍需核对实际设备。
