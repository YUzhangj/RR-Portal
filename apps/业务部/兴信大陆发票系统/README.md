# 兴信大陆发票系统

从大陆发票系统中独立提取兴信厂区的三个模块，保持原有计算与 Excel 版式处理：

- **ZURU 发票**：国际/美国订单解析，兼容 JAZ、Sky Castle、Toy Monster 香港票；日期、号码和号段筛选；单价 ×0.967；多段累计；每客独立导出及验证 CSV。
- **其他客发票**：兴信香港、远东、香港新模板分类，货款/费用/模费处理，自定义模板替换，按日期生成并打包下载。
- **面单与金额核对**：国际/美国源簿生成大陆面单，日期筛选，面单与发票金额核对及分析表导出。

三个模块切换时保留当前上传和结果；刷新会清空上传文件。解析和生成全部在浏览器完成，没有业务文件上传接口或服务器数据库。浏览器仅保存最近八次生成的时间、张数和警告数，使用独立的 `xingxin-invoice-history` 键。

## 运行

Node.js 22.12+：

```sh
npm ci
npm run dev
# http://localhost:3480/
npm test
npm run build
npm run preview
```

独立容器：

```sh
docker build -t xingxin-invoice .
docker run --rm -p 3480:80 xingxin-invoice
```

RR-Portal 入口为业务部 → **兴信大陆发票系统**，路径 `/xingxin-invoice/`；应用健康检查 `/health`（门户代理为 `/xingxin-invoice/health`）。构建使用相对资源 URL，同一产物可用于根路径或门户子路径。容器不需要持久化业务数据目录。

## 模板和历史发票

`public/` 只包含脱敏的空白格式模板。实际订单、历史发票、面单、生成输出、备份和原始源簿均不随代码发布。模板保留必要公司抬头、格式标签和工作表名称以兼容原有生成逻辑。

内置 `base-master.xlsx` 仅含 `98631` 空白模板页，**不代表已开过 98631 号发票**。默认不会依据原系统的 510 张历史票去重。如需已开票过滤、续票读取前段金额，或在旧版式输出中保留原历史票，请在第一步上传自己的 `.xlsx` 历史母版（保留 `98631` 模板页）。ZURU 新版式始终只导出本次票据。旧 `.xls` 母版/自定义模板需先在 Excel/WPS 另存为 `.xlsx`。

ZURU 新格式发票号在 **H9**、日期在 G13，C 列填货号；其他客的三个模板本支持在页面中分别替换。源文件使用完后请下载结果；换设备时需重新选择源簿及自定义模板。

## 维护与验证

核心处理位于 `src/lib/`，三个工作页位于 `src/pages/`。不依赖其他厂区源码、目录或模板；华兴与兴信是不同厂区，本系统不包含华兴模块。

`npm test` 使用合成数据验证解析、折扣、多段票、Excel 输出、日期过滤、面单核对和独立页面行为，不依赖原电脑路径或真实订单。PR 自动检查会执行测试、生产构建和容器健康检查。

模板维护脚本 `scripts/sanitize-public-templates.mjs` 需要另行提供 `@oai/artifact-tool` 运行环境，仅用于从私有原模板重新生成脱敏文件；普通运行、测试与构建均不需要该工具。重新生成后必须运行模板隐私回归并检查版式。

Excel 解析依赖使用 [SheetJS 官方安装源](https://docs.sheetjs.com/docs/getting-started/installation/nodejs/) 的固定 0.20.3 包，锁文件记录完整性校验。
