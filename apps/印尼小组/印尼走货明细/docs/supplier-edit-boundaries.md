# 供应商修改边界

- 选择供应商只修改当前物料草稿的关联及对应报关公司，不反向更新已有供应商档案。
- 新填的供应商仍可在物料保存后登记到供应商汇总；已有档案不被登记接口覆盖。未修改供应商的旧物料不重复登记旧名称。
- 编辑供应商基础资料并明确保存，只更新该 ID 的档案。不再批量改写 materials、shipment_items 或 purchase_orders 的供应商及报关公司。
- 从物料内编辑档案后，仅当前行的关联进入草稿，仍需保存物料；其他行不联动修改。保存其他物料字段时保留已存报关公司。
- 显示名称改名后，其他物料及历史单据保留原名称；如需重新关联，由用户在对应记录显式选择和保存。不会自动迁移或猜测历史名称归属。
- 本次不执行业务数据回填，也不撤销之前已经保存的改动。

验证：`SupplierSyncIntegrationTests` 覆盖唯一名称、同公司多名称、并发编辑不改写历史引用，以及选择已有供应商不覆盖公司名、报关公司、地址或联系方式。
