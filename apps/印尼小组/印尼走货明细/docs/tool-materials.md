# 工具及非生产物料

入口：左侧「工具及非生产物料」，沿用货号库/物料的访问及编辑权限。

- 类别仅有「工具」「机器设备」；原模具、耗材归入工具，原设备归入机器设备。关联货号可空，不加入产品 BOM，也不计入排期的物料用量成本。
- Excel 导入支持「货号 / 产品中文名称」双语表头格式。先核对类别、图片、匹配对象，点击「确认并保存」后才入库。
- 导入物料名称、规格、供应商、HS、单位、单件毛净重、箱尺寸、每箱数量、采购单价及币种；采购日期/单号、需求数量、箱号不进入档案。无币种时需人工确认，支持人民币、美金、港币及印尼盾。
- 编码唯一匹配或名称、规格、关联货号等唯一匹配时预选更新；不明确的默认跳过，可人工选旧物料或新增。
- 重复导入不会清空旧库；更新保留记录 ID、启用状态；空白不擦除原资料，无新图片保留旧图。
- 独立资料库管理，走货可通过“从工具库选择”直接添加工具，带入资料、采购单价和币种；本次数量人工填写。不生成采购或出库单、不扣库存。采购入口仍不接入。
- 只支持停用，不删除已被单据引用的记录。

数据：复用 materials.id；工具档案的 materials.product_code 为 NULL；tool_materials 保存类别、可选关联货号与版本。启动迁移只添加表，不自动搬迁或导入历史物料。
