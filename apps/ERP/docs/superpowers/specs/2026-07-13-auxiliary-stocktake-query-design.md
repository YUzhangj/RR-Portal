# 辅料盘点查询设计

## 目标

在“辅料报表”菜单下新增“辅料盘点查询”，采用当前系统统一的现代 Web 卡片、筛选栏、页签和表格样式。页面提供汇总查询与明细查询；双击任意明细记录时，以只读方式打开对应的辅料盘点单详情。

## 页面与导航

- 菜单名称：辅料盘点查询
- 路由：`/auxiliary-stocktake-query`
- 所属分组：辅料报表
- 页面外壳：复用 `AuxiliaryReportLayout`
- 查询视图：Ant Design `Tabs`，包含“汇总查询”和“明细查询”

## 筛选条件

- 快捷日期：上月、本月、下月
- 物料类别：默认所有类别
- 日期类型与起止日期
- 查询字段：默认辅料编号，可切换辅料名称、单号等后端支持字段
- 查询文本
- 明细页审核情况：默认全部
- 查询、精确查询、高级查询按钮沿用现有报表交互；首版查询与精确查询共用后端筛选能力，高级查询保留统一入口

## 汇总查询

按辅料聚合，显示：

- 辅料编号
- 辅料名称
- 规格
- 单位
- 系统数
- 盘点数
- 盈亏数

汇总数据由盘点明细按辅料编号归并。系统数、盘点数分别求和，盈亏数为盘点数减系统数。

## 明细查询

显示：

- 日期
- 单号
- 辅料编号
- 辅料名称
- 规格
- 单位
- 系统数量
- 盘点数量
- 盈亏数量
- 备注
- 审核

双击明细行后，根据单号加载并打开现有辅料盘点单详情抽屉。详情为只读，保留单据头、物料明细、审核状态等已有信息。

## 数据与权限

- 后端提供辅料盘点查询接口，查询范围限定为辅料类型，避免混入原料或塑胶物料。
- 接口支持日期范围、关键字、查询字段、审核状态及汇总/明细模式。
- 菜单权限名称为“辅料盘点查询”，并加入菜单目录和权限种子数据。
- 页面无打开权限时显示统一的无权访问提示。

## 错误与空状态

- 查询失败时保留当前筛选条件并显示错误消息。
- 无记录时展示空表格，不生成模拟数据。
- 双击详情加载失败时保持查询页不变并显示错误消息。

## 测试与验收

- 菜单测试：菜单项指向 `/auxiliary-stocktake-query`。
- 查询转换测试：空关键字、去除首尾空格、日期及审核参数转换正确。
- 汇总转换测试：字段映射和盈亏数计算正确。
- 明细转换测试：字段映射、审核状态及单号正确。
- 页面源码测试：使用 `AuxiliaryReportLayout`，不存在旧 ERP 主题外壳。
- 交互测试：明细行双击能以单号打开辅料盘点单详情。
- 前端测试、TypeScript 构建和后端相关测试全部通过。

## 非目标

- 不修改辅料盘点单的新增、保存、审核流程。
- 不重构原料或塑胶盘点查询页面。
- 不增加打印、Excel 导出的新后端实现。
