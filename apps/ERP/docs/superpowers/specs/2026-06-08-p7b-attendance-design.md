# P7b 考勤（缺勤登记 + 月度出勤汇总）设计

> 兴信B ERP 净室重建 · P7 算薪(M11)第二切片 · 2026-06-08

**目标**：建**缺勤登记**（请假/缺勤记录）+ **月度出勤汇总**（`实出勤天数 = 应出勤天数 − 缺勤天数`，按员工×月），作为工资表（P7d）的出勤输入。**明确排除全刷卡引擎**（刷卡机硬件 + 排班配对 + 算法10 迟到/早退计算）。

**已确认决策（与用户）**：
- 档 B：缺勤登记 + 月度出勤汇总（避开刷卡引擎）。
- 应出勤天数 = **查询参数传入**（全员同一个，按月灵活，零配置表）。
- **本期不做加班**（无加班表且工时/天数单位不同；留 P7d 工资项手录或后续加班登记）。
- 缺勤登记**录入即生效不审核**（`b缺勤登记明细` 无审核列，零改表）。
- `计算出勤` 列在本模型固定语义 = **本次缺勤折算天数**。

---

## 1. 数据模型 — 零改表

- `b缺勤登记明细`（扁平记录，无审核列）：标识号/操作日期/操作员/工号/姓名/部门/登记类型/前后段/计算出勤/日期/开始时间/结束时间/事由。FK：`工号 → 人事档案.编号`（547→员工不存在）。本模型：`计算出勤`=缺勤折算天数，`登记类型`=事假/病假/年假/旷工/…，`前后段`=全天/上午/下午（可空，默认全天）。
- `人事档案`：编号/姓名/部门编号/在职(nvarchar(2),约定 '1'=在职)/…
- `部门信息`：编号/部门。
- **无新建/ALTER 脚本**。

## 2. 缺勤登记服务（`src/ErpApi/Features/Payroll/AbsenceService.cs`）

扁平记录 CRUD（仿 P4 M6 计件录入的扁平模式，录入即生效）：
- `CreateAsync(dto, user)`：插入一条缺勤登记（工号/姓名/部门/登记类型/前后段/计算出勤/日期/开始时间?/结束时间?/事由 + 操作日期=now/操作员=user）；校验工号必填、计算出勤>0；FK 547→员工不存在。
- `ListAsync(月份?, 工号?, 部门?, page,size)`：按月份(日期∈当月)/工号/部门 过滤，JOIN 人事/部门取名。
- `DeleteAsync(ID)`：按 ID 删（无审核，直接删）。

DTO：`AbsenceCreateDto { 工号, 姓名?, 部门?, 登记类型?, 前后段?, 计算出勤, 日期, 开始时间?, 结束时间?, 事由? }`、`AbsenceRow {ID/工号/姓名/部门/登记类型/前后段/计算出勤/日期/事由}`。

## 3. 月度出勤汇总服务（`AttendanceService.MonthlyAsync(月份, 应出勤天数, 部门编号?)`）

只读 Dapper：

```sql
SELECT b.[编号] AS 工号, MAX(b.[姓名]) AS 姓名, b.[部门编号], MAX(d.[部门]) AS 部门,
       ISNULL(SUM(q.[计算出勤]),0) AS 缺勤天数,
       @应出勤天数 - ISNULL(SUM(q.[计算出勤]),0) AS 实出勤天数
FROM [人事档案] b
LEFT JOIN [b缺勤登记明细] q ON q.[工号]=b.[编号] AND q.[日期] >= @月初 AND q.[日期] < @下月初
LEFT JOIN [部门信息] d ON d.[编号]=b.[部门编号]
WHERE ISNULL(b.[在职],'1')='1' AND (@部门编号 IS NULL OR b.[部门编号]=@部门编号)
GROUP BY b.[编号], b.[部门编号]
ORDER BY b.[部门编号], b.[编号];
```

- 列出所有**在职**员工（即使无缺勤，实出勤=应出勤）；月份 yyyyMM 解析（非法→ArgumentException→400）。
- DTO `AttendanceMonthlyRow { 工号, 姓名?, 部门编号?, 部门?, 应出勤天数, 缺勤天数, 实出勤天数 }`（应出勤天数回显入参）。
- ⚠️ `在职` nvarchar(2) 约定 '1'=在职；实现时若真实数据用别的值，按实际调整 WHERE（测试种 '1'）。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 刷卡引擎庞杂/硬件耦合 | 明确排除；档 B 只做缺勤登记+月度出勤汇总喂工资。 |
| 在职值约定未知 | 默认 '1'=在职；实现时核对真实数据调整 WHERE；测试种 '1'。 |
| 缺勤登记无审核 | 表无审核列，录入即生效（零改表）；后续如需审核再加列。 |
| 计算出勤语义模糊 | 本模型固定 = 缺勤折算天数；文档/前端标注。 |
| 加班单位不一致 | 本期不做加班（天数口径）；留 P7d/后续。 |
