# 生产通知单（一单多货号·照原系统重做）设计

> 兴信B ERP 净室重建 · 表单按原系统(bmain.exe)复刻 · 2026-06-10
> ⚠️ 大工程:核心重写 P2 生产制单(一单一款号 → 一单多货号) + 波及 P4(裁床/计件加货号维)。多任务、动已测模块、有回归风险。

**目标**：把生产制单重做成原系统「生产通知单」——单据表单页(工具条+单头+货号明细网格+页签),**一个生产单号含多个货号**,每货号一行(BOM款号/款号名称/数量/比例)。新增订单字段。算3工费/算4缺料按货号展开。下游 P4 计件/裁床加货号维。

**已确认决策(用户)**：(a)照原系统重做表单;接单+BOM+制单合一;**真·一单多货号(核心重写)**;新字段**改表加列持久化**;后续逐个表单发图。

---

## 1. 现状与冲突(已审)

- 现 `生产制单` = 单头单一款号;`生产制单数量`(色×码)/`生产制单工序表`(算3)/`生产BOM物料清单`(算4) 子表均带款号、按 生产单号 关联。
- 下游耦合(已审):**无人 JOIN 生产制单单头.款号**;裁床单自带款号、按生产单号;计件取单价=`生产制单工序表 WHERE 生产单号+工序号`。
- **冲突**:一单多货号后,同一工序号会在不同货号重复 → 计件 `生产单号+工序号` 关联歧义 → 工序表/裁床/计件须加「货号」维。

## 2. 新数据模型(改表)

### 2.1 单头 `生产制单`(改表加列;款号/款式 降级为可空/不再单头语义)
新增列(幂等 ALTER 脚本 `db/10_production_notice.sql`)：`订单类型 nvarchar(10)`、`标识 nvarchar(10)`、`装箱方式 nvarchar(10)`、`订单总箱数 int`、`默认单价 nvarchar(20)`(港币档位如 HK LCL;原系统是档位非金额)。(`下单日期` 已存在。)`款号/款式` 保留列但单头不再必填(由货号明细承载)。
- 单头聚合:`计划数量=Σ货号数量`、`工序数/工序单价/物料金额` 跨货号汇总。

### 2.2 新增 `生产制单货号`(货号明细网格)
新建表(脚本)：`生产单号, 序号 int, 货号 nvarchar(40), BOM款号 nvarchar(40), 款号名称 nvarchar(60), 数量 decimal(18,4), 比例 decimal(18,4), 分析 bit`。FK 生产单号→生产制单。一行=一货号(对应一 BOM款号)。

### 2.3 子表加「货号」维(改表加列)
- `生产制单数量` 加 `货号`：每行 (生产单号, 货号, 颜色, 尺码, 数量)。
- `生产制单工序表` 加 `货号`：每行 (生产单号, 货号, 工序号, …);**计件关联键变 生产单号+货号+工序号**。
- `生产BOM物料清单` 加 `货号`：每行 (生产单号, 货号, 物料…)。

### 2.4 P4 下游加「货号」维(改表加列 + 服务/前端改)
- `裁床单` 加 `货号`(裁床针对某货号);现已带款号,补货号。
- `计件表` 加 `货号`;计件录入/单价取价 join `生产制单工序表 WHERE 生产单号+货号+工序号`;计件汇总按 货号×工序。
- ⚠️ 这是对已测 P4 的改动,需回归 P4 测试。

## 3. 算法重写(按货号)

- **算3 工费**:对每个货号(BOM款号)从 `款号明细表` 复制工序工价 → `生产制单工序表`(带货号)。计划工费=Σ各货号(货号数量×Σ工序单价)。
- **算4 缺料**:对每个货号从 `款号物料明细表` 展开 → `生产BOM物料清单`(带货号),总数量=使用数量×该货号数量;库存/缺料同现逻辑;物料金额=Σ。
- CreateAsync 改为:插单头 → 逐货号(插货号明细 + 色×码数量 + 算3工序 + 算4BOM) → 汇总回写单头。

## 4. 前端:单据表单页(替换 列表+抽屉)

- 形态:`生产通知单` 页 = 顶部工具条(新建/打开/保存/删除/审核/反审核/打印/关闭) + 单头表单(原系统字段) + 货号明细网格(序号/BOM款号/款号名称/数量/比例/分析,可增删行) + 底部页签。
- 「打开」→ 弹生产单号列表选单载入。
- 页签:**制单内容**(选中货号的 色×码数量 + 工序) / **物料清单**(选中货号的 BOM 缺料) / **MO单录入**(?) / **图片备注**(?)。
- 菜单:生产通知单挂「生产管理」组(menuTree 已有「生产通知单」→ 现指 /orders,改指新页 /production-notice 或复用 /production)。

## 5. 兼容/迁移

- 既有 单一款号 生产制单数据:视为「一个货号」——读取时若无货号明细行,以单头款号合成一行;或一次性数据迁移(既有单头款号→货号明细,既有子表货号=款号)。脚本 `db/10` 做数据回填(把现有 生产制单数量/工序/BOM 的 货号 置为其 款号)。
