# P7b 全刷卡引擎（班次/排班 + 刷卡日报计算 + 月汇总）设计

> 兴信B ERP 净室重建 · P7b 考勤增强(算法10) · 2026-06-09

**目标**：在 P7b 已有「缺勤登记 + 月度出勤汇总」基础上，补齐**全刷卡引擎**——班次定义、排班、手工录刷卡时刻，引擎按算法10配对刷卡与班次算出 迟到/早退/加班/出勤工时 写日报表，再月度汇总。依据 `D:\re_work\流程\关键算法说明_补充.md` 算法10。

**已确认决策（与用户）**：
- 刷卡数据**手工录入每日刷卡时刻**（无读卡机硬件）。
- 班次**上午+下午两段 + 宽限分钟**；晚班/法定假期倍率**延后**。
- **本期只算考勤**，不改 P7d 工资（加班费等接入工资公式延后）。
- **切两片**：① 班次管理 + 排班 ② 刷卡录入 + 日报计算引擎 + 月汇总。

**算法10（核心）**：
```
迟到分 = max(0, 实际上班刷卡 − 班次上班) − 迟到宽限   (按分钟,clamp≥0)
早退分 = max(0, 班次下班 − 实际下班刷卡) − 早退宽限
加班   = max(0, 实际下班刷卡 − 班次下班)              (分钟→小时)
出勤工时= 各段(下班−上班)累加(分钟→小时);迟到次数/早退次数 = 该段迟到分/早退分>0?1:0
```

## 数据模型 — 零改表

- `考勤_排班表`（**班次模板**）：识别(nvarchar10)/名称(nvarchar20)/上午上班/上午下班/下午上班/下午下班/晚上上班/晚上下班(均 datetime,存时刻)/总小时(real)/迟到分钟(real宽限)/早退分钟(real宽限)/直落班起计分钟。本期用 识别/名称/上午上班/上午下班/下午上班/下午下班/总小时/迟到分钟/早退分钟；晚上*留空。
- `排班表`（**排班**）：工号/姓名/日期(datetime2)/班次(nvarchar20=班次识别)/ID。
- `日报表`（**每日计算结果**）：工号/姓名/部门/日期/刷卡1..12(datetime)/上午(real工时)/下午(real)/合计时间/加班/总出勤时间/早退分(int)/迟到分(int)/迟到次数/早退次数/职称…。本期写：工号/姓名/部门/日期/刷卡1..4/上午/下午/合计时间/加班/迟到分/早退分/迟到次数/早退次数。
- `b缺勤登记明细`（P7b 已建 CRUD）：月汇总扣减用。
- 时刻存储：班次时间列存基准日 `1900-01-01 + HH:mm`；前端传/收 `"HH:mm"`，后端解析/格式化；引擎按 `TimeOfDay` 比对。
- **无新建/ALTER 脚本**。

# 第二片：刷卡录入 + 日报计算引擎 + 月汇总

## 2A. 计算引擎（`src/ErpApi/Features/Payroll/AttendanceEngine.cs`，纯函数无 DB）

`record ShiftDef(TimeSpan? 上午上班,上午下班,下午上班,下午下班, double 迟到宽限, double 早退宽限)`;
`record DailyResult(double 上午,下午,合计,加班, int 迟到分,早退分,迟到次数,早退次数)`;
`static DailyResult Compute(IReadOnlyList<TimeSpan> 刷卡, ShiftDef 班次)`：
- 刷卡升序;按段配对：上午段=刷卡中落在[上午上班−宽裕, 上午下班+裕]的最早=上班、最晚=下班(简化:取≤上午下班的最早作上午上班刷卡、≤午休前最晚作上午下班);下午段同理。
- **简化配对（本期）**：刷卡按时间排序，第1张=上午上班、第2张=上午下班/下午上班界、… 取 上午上班刷卡=第1张、下午下班刷卡=最后一张;两段工时 = 段内(下班−上班)。具体：上午=（min(上午下班刷卡,班次上午下班)−实际上午上班）;下午=（实际下午下班−max(下午上班刷卡,班次下午上班)）。**实现时取「每段：上班刷卡=该段最早卡、下班刷卡=该段最晚卡」**，段归属按刷卡时刻落在上午/下午区间判定。
- 迟到分 = clamp(实际上午上班 − 班次上午上班 在分钟, ≥0) − 迟到宽限，再 clamp≥0;早退分 = clamp(班次下午下班 − 实际下午下班) − 早退宽限;加班 = clamp(实际下午下班 − 班次下午下班)分钟/60;迟到次数=迟到分>0?1:0;早退次数同。
- 纯单测覆盖：正常全勤0迟到、迟到、早退、加班、宽限内不算迟到、缺下午段。

## 2B. 日报服务（`src/ErpApi/Features/Payroll/DailyReportService.cs`）

- `SaveAsync(工号,日期,刷卡时刻[],user)`：取该 工号×日期 排班(排班表→考勤_排班表 班次)→构 ShiftDef→`AttendanceEngine.Compute`→**整条替换**日报表(删旧 工号+日期 插新),写 刷卡1..N/上午/下午/合计/加班/迟到分/早退分/迟到次数/早退次数 + 工号/姓名/部门(查人事)。无排班→报错或按空班次记原始刷卡。
- `ListAsync(工号?,开始,结束,部门?)`：日报表查询。
- `MonthlyPunchAsync(月份,部门?)`：Σ出勤工时/Σ加班/Σ迟到次数/Σ早退次数 by 工号,当月。

## 2C. 月汇总增强 + 控制器（第二片）

- `AttendanceService.MonthlyAsync` 增强 或 新 `MonthlyAsync2`：在原 应出勤/缺勤/实出勤天数 基础上，**LEFT JOIN 日报表月聚合** 补 出勤工时/加班工时/迟到次数/早退次数。
- `DailyReportController`（`api/attendance/daily`，Menu `刷卡录入`）：GET list/POST save(保存)/可选 DELETE;出勤汇总沿用「出勤汇总」菜单（增列）。
- 权限种子补 刷卡录入。MenuCatalog 加 刷卡录入。前端「考勤管理」加 刷卡录入页（工号+日期+多刷卡时刻→保存，列出日报）;出勤汇总页加 工时/加班/迟到早退 列。

## 风险与对策

| 风险 | 对策 |
|---|---|
| 刷卡配对复杂 | 本期两段+「每段最早=上班/最晚=下班」简化配对;引擎纯函数充分单测;复杂多次进出延后。 |
| 时刻存 datetime | 班次存基准日1900-01-01+HH:mm,引擎按 TimeOfDay 比;前端 "HH:mm" 串。 |
| 跨日夜班 | 本期不支持(晚班延后),文档标注。 |
| 重复排班/日报 | 排班 Assign 按 工号+日期 去重(更新);日报 Save 按 工号+日期 整条替换。 |
| 菜单矩阵漂移 | 新增 班次管理/排班/刷卡录入 同步 MenuCatalog(gotcha#9)。 |
| 与缺勤/天数口径并存 | 刷卡引擎产「工时/加班/迟到早退」,与原「天数(应出勤−缺勤)」并列,不互相覆盖;本期不接P7d。 |
