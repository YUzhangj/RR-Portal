# 物料加权出库成本 / 金额月结 设计

> 兴信B ERP 净室重建 · P5 仓储模块剩余项 · 2026-06-08 · 在 [物料数量月结](2026-06-08-p5-material-month-end-design.md) 之上加成本层

**目标**：给物料(原料仓)月结加成本/金额层——用**全月一次加权平均法**在月结时算出库成本，快照记 期初金额/本期入金额/本期出金额/结存金额/加权单价。**仅物料口径**、**不回写出库单据**、金额列受成本保密保护。

**已确认决策（与用户）**：
- 覆盖：**仅物料(原料)**。物料采购入仓有真实单价，加权成本有意义；成品/半成品入仓单价多为手工/0、成本源是生产成本(未建)，本期不做——它们的快照金额列留 NULL。
- 方法：**全月一次加权平均**（月结时一次算，契合「单据不存余额·月结滚存」架构；移动加权需逐笔滚动余额，违背架构，不采用）。
- 不回写：月结快照记金额即可，**不改动领料单据**的单价/金额。
- 成本保密：快照新增金额列，月报接口在用户**缺 `单价` 权限**时把金额列全部置 null（沿用现有控制器脱敏模式：缺 `单价` 权限 → 单价/金额=null）。

---

## 1. 数据模型 — `结存快照表` 加金额列

幂等脚本 `db/10b_p5_material_cost.sql`（接在 09 之后，run-db.ps1 追加）：

```sql
SET XACT_ABORT ON;
IF COL_LENGTH(N'结存快照表', N'期初金额') IS NULL ALTER TABLE [结存快照表] ADD [期初金额] decimal(18,4) NULL;
IF COL_LENGTH(N'结存快照表', N'本期入金额') IS NULL ALTER TABLE [结存快照表] ADD [本期入金额] decimal(18,4) NULL;
IF COL_LENGTH(N'结存快照表', N'本期出金额') IS NULL ALTER TABLE [结存快照表] ADD [本期出金额] decimal(18,4) NULL;
IF COL_LENGTH(N'结存快照表', N'结存金额') IS NULL ALTER TABLE [结存快照表] ADD [结存金额] decimal(18,4) NULL;
IF COL_LENGTH(N'结存快照表', N'加权单价') IS NULL ALTER TABLE [结存快照表] ADD [加权单价] decimal(18,4) NULL;
```

金额列均 NULL：物料行填值，成品/半成品行留 NULL（数量月结不受影响）。

## 2. 算法 — 全月一次加权平均（月结时算，仅物料口径）

对 年月×仓库×物料编号：

- **期初数量** = 账本 Σ流水(日期<月初)（与数量月结一致，取自账本，自洽）。
- **期初金额** = **上一期快照的 结存金额**（同仓库+物料编号+口径'物料'，年月<当前的最近一条）；无上期则 **0**。
  - ⚠️ **金额是序贯的**：与数量(可独立重算)不同，期初金额只能来自上期快照的结存金额。故物料金额月结应按月份顺序逐月结；若上期未结，期初金额取 0（成本偏低，可后续反月结重算修正）。这是全月加权平均法的固有特性。
- **本期入数量** = 账本 Σ正向流水(本月)；**本期入金额** = Σ(采购入仓 + 退料) 明细 `金额`(本月,审核'1')（金额=数量×单价，服务端已算）。领料(出库)不计入金额。
- **加权单价** = (期初金额 + 本期入金额) ÷ (期初数量 + 本期入数量)；分母≤0 时取 0。
- **本期出数量** = 账本 Σ|负向流水|(本月)（领料）。
- **本期出金额** = 本期出数量 × 加权单价。
- **结存数量** = 期初+本期入-本期出（数量，已有）。
- **结存金额** = 期初金额 + 本期入金额 − 本期出金额。

数值列 decimal(18,4)。加权单价除不尽时按 decimal 精度保留；本期出金额由 本期出数量×加权单价 得，结存金额由 期初+入−出 得（残差归于结存，符合加权平均惯例）。

**实现要点**：
- 扩展 `物料账本Sql`：每个 UNION 段加一列 `金额签`（采购入仓=ISNULL(金额,0)、退料=ISNULL(金额,0)、领料=0），SELECT 增 `本期入金额 = SUM(CASE WHEN 本月 THEN 金额签 ELSE 0 END)`。映射到 `MonthEndRow.本期入金额`。
- 新增 `物料期初金额Sql`：取同仓+口径'物料'、年月<@年月 的每个物料编号最近一条 `结存金额`，装入 `Dictionary<物料编号, 期初金额>`。
- `CloseAsync` 仅当 `口径=="物料"`：查期初金额字典，逐行算 加权单价/本期出金额/结存金额，连同 期初金额/本期入金额 一并 INSERT。成品/半成品行金额列保持 null。
- `MonthEndRow` 加可空金额字段；`InsertSql` 加 5 个金额列（成品/半成品 null）。
- `ReopenAsync` 不变（删快照行即可，序贯护栏已有）。

## 3. 成本保密（关键）

`MonthEndController.Report`：取数后若用户**缺 `单价` 权限**，把每行的 期初金额/本期入金额/本期出金额/结存金额/加权单价 置 null（数量列不脱敏，与库存查询一致）。沿用半成品/成品控制器既有脱敏模式（`if (!AllowAsync(单价)) …`）。close/reopen 不加金额权限门（执行月结只需 `功能`；保密只在查看层）。

## 4. 前端

- `web/src/api/monthEnd.ts`：`MonthEndRow` 加 5 个可空字段 `期初金额?/本期入金额?/本期出金额?/结存金额?/加权单价?: number | null`。
- `web/src/utils/monthEnd.ts`：加 `moneyColumns(kind)` 返回物料口径的 5 个金额列定义(加权单价/期初金额/本期入金额/本期出金额/结存金额)，其它口径返回 `[]`。
- `web/src/pages/warehouse/MonthEnd.tsx`：列拼接为 `[...dimColumns(kind), ...数量列, ...moneyColumns(kind)]`；金额列 render 用一个 `money` 渲染器(null→"—")。成本保密由服务端置 null 落地，前端只渲染所得（无需前端判权限）。

## 5. 测试

- 后端 `MonthEndServiceDbTests` 加物料成本用例（序贯）：
  1. 上月采购入仓 100 @单价10(金额1000) → close 上月物料 → 结存数量100/结存金额1000/加权单价10。
  2. 本月采购入仓 50 @单价14(金额700) + 领料 30 → close 本月物料 → 期初数量100/期初金额1000、本期入数量50/本期入金额700、加权单价=(1000+700)/(100+50)=11.3333、本期出金额=30×11.3333≈340、结存数量120、结存金额=1000+700-340=1360。
  - 断言 加权单价≈11.3333(±0.0001)、本期出金额≈340、结存金额=1360。
- 后端 API 集成测试：缺 `单价` 权限的用户调 Report → 金额列为 null、数量列正常；有 `单价` 权限 → 金额列有值。
- 前端 `monthEnd.test.ts`：`moneyColumns("物料")` 含 加权单价/结存金额，`moneyColumns("成品")`/`("半成品")` 为空。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 期初金额序贯依赖上期快照 | 文档明确逐月结；无上期取 0；反月结可重算。期初数量仍取账本(自洽)，期初金额取上期快照结存金额。 |
| 加权单价除零 | 分母(期初数量+本期入数量)≤0 时加权单价=0、本期出金额=0。 |
| 金额泄露 | Report 缺 `单价` 权限置 null；close/reopen 不返回逐行金额（只返回结数/仓库）。 |
| 退料入库成本 | 退料金额按其单据记录的 数量×单价 计入本期入金额（与采购同口径，简化）。 |
| 成品/半成品被误算金额 | 仅 `口径=="物料"` 分支算金额；其它口径金额列 null。 |
| rounding 残差 | 结存金额=期初+入−出（非数量×单价反推），残差归结存，符合加权平均惯例。 |
