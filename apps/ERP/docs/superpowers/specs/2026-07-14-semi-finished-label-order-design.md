# 半成品标签单设计规格

## 目标

在“半成品仓库”中实现可追溯的半成品标签单，界面遵循本项目现有现代 ERP 页面规范。用户可独立新建标签单、批量选择产品、自动计算标签数量、保存并审核单据，以及预览和打印标识贴。保存的数据同时作为后续“半成品标签查询”的数据来源。

## 页面位置与权限

- 菜单位置：`半成品仓库 > 半成品标签单`。
- 菜单权限名称：`半成品标签单`。
- 操作按现有权限模型分别校验：打开、新建、保存、删除、审核、反审核、打印。
- 保存、删除、审核和反审核写入操作日志。

## 单据页面

### 表头

- 电脑单号：新单为空或显示待生成状态，首次保存时由后端生成且保持唯一。
- 日期：默认当前日期，可修改。
- 备注一、备注二：两个独立备注字段，对应参考界面的两行备注。
- 操作员：当前登录用户，只读。
- 审核状态：未审核或已审核，只读展示。

### 明细

每条明细包含：

- 配件编号
- 客户
- 产品货号
- 产品名称
- 产品装配名称
- 数量
- 每箱数量
- 预计标签数
- 实需标签数
- 备注

新建状态提供空白明细行。用户点击产品相关空白单元格打开产品选择窗口，也可删除已选明细。

## 产品选择窗口

- 数据来源为现有款号物料/装配资料，不复制维护另一套产品主数据。
- 支持按产品货号、产品名称、配件编号、客户或产品装配名称查询。
- 支持普通查询、精确查询、全选、反选和多选确认。
- 列表显示：配件编号、产品装配名称、客户、产品货号、产品名称、加工单价、库存单价。
- 多选确认后将产品资料带回标签单。
- 同一配件编号已存在时不新增重复行，而是合并数量并重新计算标签数。

## 标签数量规则

- 数量和每箱数量必须为非负数。
- 当每箱数量大于 0 时：`预计标签数 = ceil(数量 / 每箱数量)`。
- 新增产品时，实需标签数默认等于预计标签数。
- 数量或每箱数量变化时重新计算预计标签数。
- 用户手工修改过实需标签数后，重新计算预计标签数不覆盖该人工值。
- 每箱数量小于等于 0 时不自动计算，并提示用户补充每箱数量。
- 实需标签数必须是非负整数；值为 0 的明细不生成标签。

## 单据生命周期

- 新建：清空表头和明细并进入编辑状态。
- 打开：通过单据选择窗口打开历史标签单。
- 保存：校验表头和明细后，以事务方式保存表头与明细。
- 删除：仅允许删除未审核单据，并要求删除权限。
- 复制：复制当前单据内容为未保存新单，不复制单号和审核信息。
- 前单/后单：按单据日期和内部 ID 切换相邻单据。
- 审核：保存后的未审核单据可审核；审核后页面只读。
- 反审核：具有反审核权限时恢复为可编辑状态。
- 已审核单据禁止保存、删除及修改明细。

## 标签预览与打印

- “标识贴”操作按每条明细的实需标签数展开打印数据。
- 预览显示产品货号、产品名称、产品装配名称、配件编号、客户、标签序号和总标签数。
- 标签数为 0 的明细跳过。
- 打印前再次校验实需标签数；存在非法值时阻止打印并定位到对应明细。
- 使用浏览器打印能力生成可打印版式，不依赖本地桌面 ERP 客户端。

## 后端与数据存储

新增标签单表头与明细表：

- 表头保存单号、日期、两处备注、操作员、审核状态、审核人、审核时间及创建/更新时间。
- 明细保存表头关联、行号、产品快照字段、数量、每箱数量、预计标签数、实需标签数和备注。
- 产品名称等字段按保存时快照写入，保证历史单据不会因主数据改名而失真。
- 首次保存由后端原子生成单号，数据库唯一索引防止重复。
- 表头与明细的新增、更新和删除在同一数据库事务中完成。
- 查询接口返回完整表头和有序明细；产品选择接口仅返回可用于半成品标签的产品资料。

## 前端结构

- 新增半成品标签单 API 模块，封装读取、保存、删除、审核、反审核、相邻单据和产品选择接口。
- 页面拆分为单据页、产品选择弹窗和标签打印预览，避免在一个组件中混合所有职责。
- 复用现有页面的 Card、Form、Table、按钮工具栏、权限钩子和错误提示方式。
- 页面路由和菜单均配置在半成品仓库模块下，不放入辅料报表或其他仓库模块。

## 错误处理

- 后端对不存在的单据返回 404，对审核锁定冲突返回 409，对输入错误返回 400，对权限不足返回 403。
- 前端保留用户当前输入并显示明确错误，不因接口失败清空表单。
- 重复提交保存由按钮加载状态和后端事务共同防护。
- 产品主数据缺少每箱数量时允许选入，但明确提示用户补充后再打印。

## 测试与验收

- 后端测试：单号生成、事务保存与读取、重复产品合并输入、审核锁定、反审核、删除限制、标签计算和权限。
- 前端测试：页面菜单位置、产品多选回填、重复行合并、预计标签数计算、人工实需标签数保护、审核只读和打印展开。
- 构建前端与后端，执行现有测试套件。
- 发布前后端后验证目标路由可访问、页面视觉与其他现代页面一致、关闭终端后隐藏服务仍可运行。
