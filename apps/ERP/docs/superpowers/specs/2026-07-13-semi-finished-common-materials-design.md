# 半成品共用物料表设计说明

## 1. 目标

在“半成品仓库”菜单下实现独立的“半成品共用物料表”，页面采用项目当前统一的现代前端样式。列表展示半成品产品与共用物料设置，双击任意数据行进入现有“装配物料设置”详情页，并允许修改、保存和审核。

本功能不是“辅料报表”功能，也不是“塑胶共用物料表”。不得修改或复用这两个模块的业务表、路由和页面。

## 2. 功能边界

### 包含

- “半成品仓库”下新增菜单“半成品共用物料表”。
- 独立列表页、独立查询接口和独立菜单权限。
- 按旧系统截图提供列表字段、筛选、模糊查询和精确查询。
- 单击选择行，双击进入“装配物料设置”详情。
- 扩展现有装配物料详情的数据加载与保存，使页面上可编辑的产品扩展字段能够持久化。
- 审核和反审核状态持久化，并在列表中显示和筛选。
- 数据库迁移、权限种子、自动化测试、前后端构建发布和隐藏运行。

### 不包含

- 不修改“辅料报表”菜单或辅料盘点查询。
- 不修改“塑胶共用物料表”页面及 `[塑胶共用物料表]`。
- 不修改“装配物料汇总表”的统计口径和现有报表。
- 不照搬旧系统窗口、像素风格或桌面程序布局。

## 3. 菜单与路由

- 菜单分组：`半成品仓库`
- 菜单名称：`半成品共用物料表`
- 列表路由：`/semi-finished-common-materials`
- 详情路由：复用 `/assembly-material-setup`
- 双击跳转：`/assembly-material-setup?款号={产品货号}&return=/semi-finished-common-materials`
- 详情页关闭时优先返回 `return` 参数指定的列表，否则保持现有关闭行为。

## 4. 列表页面

### 4.1 统一视觉

使用项目现有现代页面结构：白色内容卡片、紧凑工具栏、统一表单控件、标签页和数据表格。不得创建旧式彩色标题栏、桌面窗口边框或固定像素画布。

### 4.2 查询条件

- `重复内容`：全部、显示重复。
- `待操作物料`：全部、待设置、已设置。
- `审核情况`：全部、未审核、已审核。
- `请选择条件`：产品货号、产品名称、产品装配名称、配件编号、共用物料编号、客户。
- 查询文本。
- `查询`：包含匹配。
- `精确查询`：完全匹配。
- 工具按钮：表格设置、导出 Excel、打印、关闭；按照现有权限和数据状态启用。

### 4.3 列表字段

列表以一条最新产品装配设置为一行，字段顺序如下：

1. 客户
2. 产品货号
3. 产品名称
4. 产品装配名称
5. 库存单价
6. 配件编号
7. 共用物料编号
8. 调整审核
9. 备注内容

没有“单价”权限时，后端不返回真实库存单价，前端显示 `***`，不能仅依靠前端隐藏。

### 4.4 筛选定义

- `显示重复`：仅显示同一非空“共用物料编号”被两个或以上不同产品货号使用的记录。
- `待设置`：共用物料编号为空；`已设置`：共用物料编号非空。
- `未审核`、`已审核`：按半成品共用物料扩展记录的审核状态筛选。
- 所有筛选、权限和分页均由服务端执行。

### 4.5 交互

- 单击一行只改变选中状态。
- 双击数据行打开对应产品货号的装配物料设置详情。
- 产品货号为空的异常记录不能打开，页面提示明确错误。
- 查询失败、无权限和保存失败使用项目统一消息组件反馈。

## 5. 数据模型

### 5.1 现有数据继续使用

- `[款号物料总表]`：产品装配主信息。
- `[款号物料明细表]`：装配物料明细。

列表每个产品货号仅取最新一条主记录，避免历史版本重复显示。产品和客户字段优先取主表，缺失时再从明细表回退。

### 5.2 新增扩展表

新增 `[半成品共用物料设置]`，不改变旧系统核心表结构：

- `ID`：自增主键。
- `产品货号`：唯一业务键，非空。
- `产品装配名称`。
- `配件编号`。
- `共用物料编号`。
- `装配方式`。
- `类别`。
- `库存单价HK`：decimal。
- `其他成本HK`：decimal。
- `需求用量`：decimal。
- `单位`。
- `半成品计算库存`：bit。
- `备注内容`。
- `调整审核`：bit。
- `审核人`、`审核时间`。
- `更新人`、`更新时间`。

为 `产品货号` 建唯一索引，为 `共用物料编号`、`调整审核` 建查询索引。迁移脚本必须可重复执行。

### 5.3 报价对象

装配物料设置右侧的加工厂/供应商报价不是临时 UI 数据。新增 `[装配物料报价]` 持久化：

- 产品货号、物料编号、物料名称。
- 合作方类型：加工厂或供应商。
- 合作方编号、合作方名称。
- 报价日期、货币、单价、港币价、对比相差、相差比例。
- 是否默认、顺序、备注。

保存详情时，主表、物料明细、扩展信息和报价信息必须在同一数据库事务中提交；任一步失败时全部回滚。

## 6. 字段映射

- 客户：主表客户名称，缺失时回退客户或明细客户名称。
- 产品货号：主表款号。
- 产品名称：主表款式；为空时回退明细款式。
- 产品装配名称：扩展表产品装配名称；为空时回退产品名称。
- 库存单价：扩展表库存单价 HK$。
- 配件编号：扩展表配件编号；为空时回退主表产品编号。
- 共用物料编号：扩展表共用物料编号。
- 调整审核：扩展表调整审核，显示“已审核”或“未审核”。
- 备注内容：扩展表备注内容；为空时回退主表备注。

## 7. 后端接口

### 7.1 列表

`GET /api/semi-finished-common-materials`

参数：重复内容、待操作物料、审核情况、查询字段、关键词、是否精确、页码、每页数量。

返回：记录总数、分页数据、当前用户可执行操作。查询使用参数化 SQL，服务端校验查询字段白名单。

### 7.2 详情加载与保存

扩展现有装配物料设置接口的 DTO：

- 加载时同时返回主信息、物料行、扩展信息、加工厂/供应商报价。
- 保存时一次提交完整详情，并在事务内更新四类数据。
- 保持旧调用方兼容：新增字段可选，未提交扩展字段时不得清空已有扩展数据。

### 7.3 审核

- `POST /api/semi-finished-common-materials/{产品货号}/audit`
- `POST /api/semi-finished-common-materials/{产品货号}/reverse-audit`

审核后普通编辑和保存被禁止；反审核后恢复编辑。两项操作分别检查“审核”和“反审核”权限，并记录操作人和时间。

## 8. 权限

- 新增菜单权限：`半成品仓库 / 半成品共用物料表`。
- 列表检查打开、导出、打印和单价权限。
- 详情继续检查现有“装配物料设置”打开、修改、审核和反审核权限。
- 新权限种子默认授予管理员，并在本地数据库实际执行，不只新增 SQL 文件。

## 9. 前端详情改造

复用现有 `BomSetupPage`，不复制第二套详情页面：

- 根据产品货号自动加载客户、产品名称、主信息、物料行和报价行。
- 允许修改扩展字段、物料明细、加工厂/供应商及报价。
- 保存后重新读取服务端结果，避免 UI 与数据库状态不一致。
- 已审核时字段和保存按钮只读，保留反审核按钮。
- 从列表进入时关闭返回半成品共用物料表，并保留原查询条件。

## 10. 测试与验收

### 后端测试

- 最新产品版本只返回一行。
- 重复、待设置、已设置、审核状态和精确/模糊查询正确。
- 无单价权限不泄漏库存单价。
- 扩展信息与报价可以保存并重新读取。
- 保存事务失败时不产生部分数据。
- 审核后禁止修改，反审核后恢复。
- 无菜单权限和无操作权限返回 403。

### 前端测试

- 菜单位于半成品仓库且路由正确。
- 查询控件生成正确请求参数。
- 单击选中、双击进入正确产品详情。
- 详情能加载、编辑、保存并回显扩展字段与报价。
- 已审核状态只读，权限按钮正确隐藏或禁用。
- 关闭详情返回列表并恢复查询状态。

### 发布验收

- 运行后端测试和前端测试。
- 执行前端生产构建、后端发布和数据库迁移/权限种子。
- 以隐藏后台进程重启服务，关闭终端后网页仍可访问。
- 验证 `/semi-finished-common-materials`、详情路由和 API 均返回成功。
- 使用浏览器检查页面无重叠、无截断、横向表格可滚动，并与项目其他现代页面风格一致。

## 11. 完成标准

用户可在“半成品仓库”打开“半成品共用物料表”，按截图字段查询和筛选数据，双击一行进入统一现代风格的“装配物料设置”，修改并保存物料、共用设置和加工厂/供应商报价；刷新后数据仍存在，审核状态和权限生效，且不影响辅料、塑胶和现有装配报表模块。
