# BOM 物料设置「复制单」— 全套接入

日期：2026-07-28

## 背景
旧 ERP 功能：打开已有 BOM → 点「复制单」→ 复制该 BOM 物料资料，用于快速做同一货号的另一版本/另一货号的 BOM。
Web 端 `BomSetupPage`（/bom-setup 与 /assembly-material-setup 共用）工具栏此前无复制按钮。

## 复制语义（决策）
- 复制内容：与 `GetMaterialsViewAsync` 一致的三段 —— `款号物料明细表`（BOM 明细，含随行的客户编号/客户名称/日期/单位）、`半成品共用物料设置`（装配扩展，源有才复制）、`装配物料报价`（报价行，整组替换；源无报价则清空目标报价）。
- 写入复用 `ReplaceMaterialsAsync` 的整组替换语义：目标行重新落目标款号/款式，顺序号重排。
- 扩展段 MERGE 不写 `调整审核/审核人/审核时间`，故目标复制后始终为未审核状态。
- 目标已有 BOM 且未指定 `覆盖=true` → 409；`覆盖=true` 时整组替换。
- 目标已审核 → 409（复用「已审核须先反审核」检查）；源无 BOM → 400；源/目标款号不存在 → 404；目标=源 → 400。
- 注：前置检查与写入非同一事务（同本服务只读聚合的项目级权衡），`ReplaceMaterialsAsync` 内部仍事务化。

## API
```
POST /api/styles/{款号}/copy
请求体: { "目标款号": "X", "覆盖": false }
权限: 款号资料·保存（同 PUT materials）
响应: 204 NoContent
错误: 400 {消息} 目标款号为空 / 目标=源 / 源无 BOM 无法复制
      404 {消息} 源或目标款号不存在
      409 {消息} 目标已有 BOM（未覆盖）/ 目标已审核
审计: 款号物料明细表 · 复制 · 款号=源→目标
```
